# Mendelian_Genetics_Interpretor_2
Mendelian Genetics Interpreter

Python program designed to analyze a dihybrid Mendelian cross between two parents. The user enters the genotypes of Parent 1 and Parent 2, and the program generates possible offspring genotypes and analyzes their genetic outcomes.

Main Functions of the Program
1. Takes Parent Genotypes as Input: The program asks the user to enter the genotypes of both parents, such as AaBb.
2. Validates the Genotypes: It checks whether the entered genotypes contain exactly four characters. If the condition is not satisfied, the program stops.
3. Extracts Alleles: Each parent's four alleles are extracted and stored in a list for further genetic analysis.
4. Generates Gametes: The program separates the two genes and combines their alleles to identify the possible gametes produced by each parent.
5. Creates a Punnett Square: It combines the gametes of both parents to generate all possible offspring genotypes.
6. Generates Offspring Genotypes: The program stores all offspring combinations in a list for further analysis.
7. Counts Genotypes: It calculates the number of occurrences of each offspring genotype using a dictionary.
8. Calculates Genotype Percentages: The program determines the percentage of each genotype among all possible offspring combinations.
9. Determines Phenotypes: It attempts to classify offspring into dominant and recessive phenotype categories based on their genotypes.
10. Counts Phenotypes: The program counts the offspring assigned to each phenotype category.
11. Calculates Phenotype Percentages: It calculates the percentages of the classified dominant and recessive phenotypes.
12. Analyzes Homozygous and Heterozygous Conditions: It identifies offspring that are homozygous for both genes, heterozygous for both genes, or homozygous for one gene and heterozygous for the other.
13. Identifies Possible Offspring: It uses a set to identify the unique offspring genotypes generated by the cross.

Purpose of the Project
The purpose of this project is to apply basic Python programming concepts to genetics and demonstrate how computational methods can be used to study Mendelian inheritance, gamete formation, Punnett squares, and offspring genotype distributions.

Note: The current phenotype analysis is simplified and does not correctly evaluate both genes independently. Genotype validation also checks only the input length, not its biological validity.
